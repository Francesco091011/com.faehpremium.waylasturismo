# Áncash Explorer

App Android para turismo en Áncash, Perú. Incluye mapas, destinos, rutas, clima, gastronomía y más.

## Estructura inicial
- Jetpack Compose
- Navegación modular
- Carpetas para UI, datos, modelos, navegación y utilidades
