# Waylas Turismo

La Aplicación Oficial de Turismo en el Departamento de Áncash, Perú.
Incluye mapas, destinos, rutas, clima, gastronomía y más.

## Funciones

- **Exploración de Destinos**: Descubre los lugares más emblemáticos de Áncash con información detallada y fotos.
- **Mapas Interactivos**: Navegación integrada con OpenStreetMap para localizar atractivos, servicios y rutas en tiempo real.
- **Guía Gastronómica**: Información completa sobre platos típicos y una selección de los mejores restaurantes.
- **Rutas y Tours**: Sugerencias de itinerarios, caminos y acceso a ofertas de tours organizados.
- **Clima en Tiempo Real**: Consulta las condiciones meteorológicas actuales para planificar tus excursiones.
- **Alojamiento**: Directorio actualizado de hoteles, hostales y refugios en la región.
- **Turismo Arqueológico y de Aventura**: Detalles sobre sitios históricos y actividades como trekking, escalada y más.
- **Calendario de Eventos**: Mantente al tanto de las festividades patronales, ferias y eventos culturales.
- **Herramientas para el Viajero**: Consulta el tipo de cambio actualizado y recibe consejos prácticos (Tips) para tu estancia.
